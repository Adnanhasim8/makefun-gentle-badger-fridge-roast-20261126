# Fridge Roast: One Line, Biggest Laugh

Entry for the make.fun competition `u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb`.

`main.py` (Python 3.13 standard library only, no network) writes one roast line
to `/output/entry.txt`:

> The ice maker makes three cubes a night and still acts like it built the pyramids.

The line was picked from 18 candidates scored against the judge's rubric
(laugh, on-target, fridge-specific, tight, fresh): one concrete image, petty,
and the mystery left unanswered.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
